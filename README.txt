CANDYVERSE Floating AR

FILES
- index.html
- CANDYVERSE_AR_logo.png

DEPLOY
1. Upload BOTH files to the ROOT of the GitHub Pages repository (same folder).
2. Keep the filenames exactly as shown.
3. Enable GitHub Pages from the main branch / root if not already enabled.
4. Open the published website URL on iPhone Safari (must be HTTPS).
5. Tap Open camera and allow camera access.

HOW IT WORKS
This page displays the original transparent CANDYVERSE logo as a draggable overlay over the live camera feed. It is camera-view floating artwork, not a spatially anchored AR object. It will appear on the iPhone display only; it cannot physically emerge outside the phone. It does not automatically stick to a wall/floor or track a hand.
